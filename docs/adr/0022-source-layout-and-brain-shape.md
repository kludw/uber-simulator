# 0022. Source layout and brain shape

- Status: Accepted
- Date: 2026-10-02

## Context

Milestone 1 builds the pure brains of driver, dispatch, and rider services (0017) in one package (0019). Implementer agents work ticket by ticket with minimal context, so module placement and the brain interface must be fixed up front or each ticket invents its own.

## Decision

We will use:

```
src/
  shared/          result.ts, grid.ts, random.ts, messages.ts (+ *.test.ts)
  driver/brain.ts  (+ brain.test.ts)
  dispatch/brain.ts
  rider/brain.ts
```

- Tests colocated as `*.test.ts`.
- Each brain exports a start function and one `decide` function: `decide(state, input, random) -> { state, outputs }`. `input` = discriminated union of messages the service receives (tick, events, commands, offers). `outputs` = messages to publish (events, commands, offer replies), in emission order. Pure, synchronous.
- `src/shared/messages.ts` holds event, command, and offer message types, named per the `domain` skill. The first ticket needing a message adds it.
- A driver commits to a trip when it accepts an offer (`en_route`). If dispatch already expired that offer, dispatch's `trip.offer_expired` returns the driver to `idle`; dispatch ignores the late accept.
- Trip IDs are generated by the rider service (single instance) and carried in `request_trip`.

## Rationale

- One shape for all brains makes them interchangeable for the shell (milestone 2) and predictable for agents.
- `shared/` only for modules used by more than one service; everything else stays in its service folder.
- Resolving the expiry race through an event keeps dispatch the single owner of trips (0018) without a second handshake.

## Alternatives considered

- Flat `src/`: fine now, unclear ownership once shells and adapters arrive.
- Driver waits for `trip.matched` before driving: one more message round trip and an extra driver state.

## Consequences

- Shells (milestone 2) wrap `decide` without changing brains.
- `messages.ts` grows with every ticket; split it if it gets unwieldy.
